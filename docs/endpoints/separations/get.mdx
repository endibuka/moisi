---
title: Get a separation
description: Fetch a single job, including signed download URLs once it's done.
api: GET /v1/separations/{id}
---

Returns the job by id. When `status === "completed"`, the response also
includes `stem_urls` — signed download URLs (1h TTL) for each stem the
job produced. Call this in a polling loop after
[POST /v1/separations](/endpoints/separations/create) until the job
finishes.

## Request

### Headers

| Name | Required | Value |
| --- | --- | --- |
| `Authorization` | yes | `Bearer mk_live_…` |

### Path

<ParamField path="id" type="string" required>
  Job id, returned by [POST /v1/separations](/endpoints/separations/create).
</ParamField>

## Response

<ResponseField name="id" type="string">UUID of the job.</ResponseField>
<ResponseField name="status" type="string">
  One of `pending`, `processing`, `completed`, `failed`.
</ResponseField>
<ResponseField name="original_name" type="string">
  Filename as you supplied it on creation.
</ResponseField>
<ResponseField name="input_path" type="string">
  Storage path of the source file (the `path` from
  [POST /v1/uploads](/endpoints/uploads/create)).
</ResponseField>
<ResponseField name="stems" type="object | null">
  Storage paths of the resulting stems (`vocals`, `drums`, `bass`,
  `guitar`, `piano`, `other`). `null` until the job completes. Use
  `stem_urls` below for ready-to-fetch signed URLs.
</ResponseField>
<ResponseField name="stem_urls" type="object | null">
  Signed download URLs for each stem, valid 1 hour. Only populated when
  `status === "completed"`. Refresh by calling this endpoint again.
</ResponseField>
<ResponseField name="error" type="string | null">
  Failure reason when `status === "failed"`.
</ResponseField>
<ResponseField name="duration_seconds" type="number | null">
  Duration of the source audio.
</ResponseField>
<ResponseField name="created_at" type="string (ISO 8601)" />
<ResponseField name="updated_at" type="string (ISO 8601)" />
<ResponseField name="job_type" type="string">
  `separation`, `vocal_isolation`, or `music_generation`.
</ResponseField>

## Polling

Poll at most once every 2 seconds. Separation jobs typically finish in
30–90 seconds depending on track length.

<Tip>
  If you need to fetch stems later (after the 1h signed URL expires),
  just call this endpoint again — fresh URLs are minted each time.
</Tip>

## Errors

| Code | When |
| --- | --- |
| `missing_api_key` / `invalid_api_key` / `revoked_api_key` | Auth. |
| `not_found` | No job with that id (or it belongs to another account). |
