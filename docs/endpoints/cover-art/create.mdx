---
title: Generate cover art
description: Create a cover image for an existing separation or song job.
api: POST /v1/cover-art
---

Generates a cover image (PNG, typically square) for one of your existing
jobs. The image is generated by Gemini using the job's display name plus
an optional creative-direction `prompt`, stored to object storage, and
linked to the job's `cover_art_path`.

This endpoint works for any job you own — both separation jobs
(uploaded tracks) and song jobs (music generation).

## Request

### Headers

| Name | Required | Value |
| --- | --- | --- |
| `Authorization` | yes | `Bearer mk_live_…` |
| `Content-Type` | yes | `application/json` |

### Body

<ParamField body="jobId" type="string" required>
  Id of an existing separation or song job. Must belong to your account.
</ParamField>

<ParamField body="prompt" type="string">
  Optional creative direction. Up to 500 characters. Examples: mood,
  palette, motifs ("vintage analog, warm sepia, neon highlights"). Mixed
  with the job's title to form the final prompt sent to Gemini.
</ParamField>

## Response

`201 Created`. Returns a short-lived signed URL for the freshly
generated image and the storage path it was saved to.

```json
{
  "jobId": "01HF…",
  "path": "8f3a…/01HF…/cover-art-1716304800123.png",
  "url": "https://…signed-1h-url…",
  "expiresAt": "2026-05-21T10:00:00.000Z"
}
```

After this returns, the `cover_art_path` field on the job row points at
`path`. Subsequent calls to
[GET /v1/separations/{id}](/endpoints/separations/get) or
[GET /v1/songs/{id}](/endpoints/songs/get) will include a fresh signed
`cover_art_url` for the saved image.

## Examples

### Minimal

```bash
curl https://app.moisi.app/api/v1/cover-art \
  -H "Authorization: Bearer mk_live_…" \
  -H "Content-Type: application/json" \
  -d '{"jobId": "01HF…"}'
```

### With creative direction

```bash
curl https://app.moisi.app/api/v1/cover-art \
  -H "Authorization: Bearer mk_live_…" \
  -H "Content-Type: application/json" \
  -d '{
    "jobId": "01HF…",
    "prompt": "vintage analog photo, warm sepia tones, neon highlights, soft grain"
  }'
```

## Re-generating

Calling this endpoint on the same `jobId` again overwrites the linked
`cover_art_path`. The previous image is left in storage; only the link
on the job row changes. If you want to keep an older image, save its
`path` before re-generating.

## Errors

| Code | When |
| --- | --- |
| `missing_api_key` / `invalid_api_key` / `revoked_api_key` | Auth. |
| `invalid_request` | `jobId` missing, `prompt` not a string, or `prompt` exceeds 500 chars. |
| `not_found` | No job with that id, or it belongs to another account. |
| `internal_error` | Gemini failure, storage upload error, or DB write error. Safe to retry. |
